Measurement details

Work rates use changes between certified ledger snapshots. Artifact bytes describe accepted updates, not network wire traffic. Live interface bandwidth and CPU/GPU measurements are available in the observer console and terminal dashboard. Compute rates appear when workers report operation counts.

How it works

Every contribution has a history.

Publish source texts and token Frags. A Blueprint pins the corpus, tokenizer and partitions.

Contribute the work

Validators agree on the ledger. Required verification receipts promote contributions into certified checkpoints.

Data and verification

The corpus includes Nasjonalbiblioteket's CC0 bokselskap.no distribution, discovered through data.norge.no. The Blueprint preserves source hashes, text extraction, tokenizer and source-family holdouts.

Training and separate-process replay use one GPU and a pinned runtime. Receipts identify the exact replay intervals. Evaluation uses fixed held-out samples; model configurations differ in capacity, data and training exposure.
