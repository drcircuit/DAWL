What can an outsider check?

Signatures, exact file hashes, the recorded recipe and public quorum certificates can be inspected now. Rebuilding token windows, checking all weight bytes and repeating training also requires the pinned corpus and model artifacts; the downloadable evidence bundles contain metadata rather than the full weights.

Signatures attribute records to keys. The experiments here use one project operator. They do not establish independent institutions, complete upstream pretraining lineage, or a causal link from a particular passage to a generated answer.

The human-trust experiment

The first participant prototype uses six fixed, researcher-authored advice texts across three constructed situations: extra loan repayment, total fund fees and refinancing. Documentation varies while each advice variant stays word-for-word identical. The earlier three-model comparison remains a separate exploratory experiment.

Advice and model-development documentation are separate components. The documentation is not presented as proof that the model generated the researcher-written advice. Pilot responses remain local and are not displayed here.
