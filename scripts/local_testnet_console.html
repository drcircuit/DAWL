Verification acceptance policy

Each named verifier fetches the committed parent and all shard updates, replays the actual forward/backward/SGD steps, checks exact output hashes, recomputes the token-weighted average, and serves the artifacts before signing. All named verifiers must agree. The Oracle certifies their signed claims; this is not a cryptographic proof of computation.
