01 / Reconstruction

Ship the ingredients. Rebuild the vectors.

A Frag carries token IDs. A pinned input matrix gives those IDs their numerical meaning. Each node reconstructs the same input vectors locally and checks the committed bytes.

The mathematical contract

Row lookup, not contextual inference

Vf=Ep[tf,:]

Ep is the profile's fixed input table. tf is the Frag's token sequence. Gather copies the corresponding F32 rows exactly.

cf=SHA256(F32LE(Vf))

GPU bytes must match both NumPy replay and the earlier CPU commitment. This verifies input embeddings, not attention, inference or learned semantic quality.

02 / Provenance

Shared source. Separate numerical meanings.

Tokenizer and model choices define different coordinate systems. Blueprints bind each profile to its exact inputs, while the underlying source objects can be shared.

Observed · six certified heads

Tokens from the same 13 books

Identical source bytes and fixed UTF-8 Frag boundaries. Token count is corpus-specific and is not a measure of model quality.

Identity binds the recipe

A hash of bytes is only the beginning

hi=H(hparents,profile,recipe,artifact)

Conceptual binding rule: canonical record bodies include parent references, policy and artifact descriptors. Signatures attribute those records to keys; Oracle quorum certifies accepted state.

Changing the tokenizer, table, token bytes or parent breaks a checked binding. Authentic provenance does not establish rights, truthfulness of source claims or data quality.

The update rule

A small, composable training payload

Weffective=W0+2BA

The base W0 and rank-8 projection A stay fixed. Each trainer updates B: 184,320 FP32 values, or 737,280 bytes.

Bt+1=∑knk∑jnjBt,k

nk counts valid target tokens. Every verifier reduces shards in the same order using FP64 accumulation, then casts to FP32. Fixed A makes averaging these adapters algebraically meaningful.

Local multi-step SGD followed by averaging is not generally identical to centralized SGD. Completion is asynchronous within a round; later rounds wait for a verified common parent.

04 / Faults and verification

Failures must change state predictably.

Availability, integrity and agreement are separate concerns. An unavailable worker can lose a lease without being labeled malicious. A signed claim can still fail numerical replay.

Interactive rules + observed evidence
Illustration · equal validator power

How many validators can go offline?

Psigned>23Ptotal

Toggle validators. This changes the illustration only.

Quorum is necessary for commits; enough reachable honest validators, connectivity and proposal progress are also required. Training has its own verifier requirements.

Observed: the earlier cluster halted with two validators and recovered with three. In the current run, three validators certified training progress while validator 3 remained at height 893.

Illustration · uniform sampling without replacement

What can a spot check detect?

P(detect)=1−(N−mk)(Nk)

N = 1,000 is illustrative, not a recorded trial. Assumes fixed bad Frags and unpredictable uniform selection after commitment. It does not model collusion, adaptive corruption or poisoned-but-correctly-processed data.

The cold consumer fetched 299.668 MB in 3,680 objects, verified the quorum and full state history, retokenized the source, loaded the model and ran a CPU forward pass. The provider, both trainers and the other verifier were stopped.

Next hardening: verifier replacement, recovery from accepted corrupt or withheld updates, durable availability challenges, Sybil-resistant admission, WAN/NAT transport, hardware compatibility and model-quality gates. Full replay is the expensive correctness baseline; a sampling protocol needs its own threat model.
